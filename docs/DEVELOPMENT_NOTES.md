# 开发备忘录

## 地图 Key 管理

当前需求广场已支持可选接入高德 JavaScript API。MVP 阶段为了保持本地可运行，页面允许在浏览器中填写 Web Key 和安全密钥，并保存到 `localStorage`。

后续生产化时需要调整：

- 高德 Web Key、`securityJsCode` 不得提交到仓库。
- dev/test/prod 环境分别配置独立 Key，避免演示环境影响正式配额。
- 推荐由后端配置或环境变量下发前端运行时配置，例如 `/api/config/map`。
- 生产环境应限制 Key 的来源域名，并定期轮换。
- README 中只保留配置方式和占位示例，不出现真实 Key。

## XLSX 导入

`example.xlsx` 已作为当前需求导入格式的样例文件。后续迁移 Spring Boot 后，建议把本地路径导入替换为 multipart 上传，并在服务端保存导入批次、失败行和原始文件归档记录。

## 本地账号数据库

- `data/ptagent-accounts.json` 用于零依赖阶段的账号与教师资料持久化，已加入 `.gitignore`，不得提交真实注册信息。
- 可用 `PTAGENT_DATA_DIR` 把数据文件迁移到仓库外目录。
- 当前文件数据库不是 MySQL 的替代品；它不提供多进程并发、复杂查询、备份恢复和字段级迁移。
- 生产迁移使用 `database/migrations` 下的版本化 SQL；账号采用微信、QQ和手机号身份绑定，不再维护平台密码。

## 第三方登录适配

- 当前微信/QQ登录按本地身份标识匹配账号，手机号验证码由服务端内存生成并在 `demoCode` 中回传，只用于离线验收。
- 生产环境应使用微信开放平台 OAuth、QQ互联 OAuth 和短信服务商，服务端用授权码换取稳定的第三方用户标识。
- OAuth App ID、App Secret、短信密钥和签名模板必须通过环境变量或密钥管理服务注入，不得提交到仓库。
- 当前已实现单进程发送冷却、次数上限、错误上限和一次性消费；生产环境仍需使用 Redis 实现多实例限流，并增加 IP/设备风控和审计记录。

## 权限与审计

当前零依赖 MVP 已增加服务端内存会话：登录签发 12 小时 Bearer Token，支持 `/api/auth/me` 恢复和 `/api/auth/logout` 失效。`ApiRouter` 将登录用户注入 `ApiRequest`，controller 覆盖客户端提交的操作者 ID，再由 `AccessGuard` 校验账号状态和角色权限。`0.9.0-rc2` 已具备单进程登录限流、验证码防刷、请求上限、同源 CORS、安全响应头、需求隐私脱敏、请求上下文和本地链式审计。

后续生产化时需要调整：

- 当前令牌和限流状态随服务重启失效，也未实现多实例共享与续期；生产环境应迁移到 Spring Security Session/JWT，并使用 Redis 或数据库维护可撤销状态与分布式限流。
- `AccessGuard` 可迁移为 Spring Security 权限注解、拦截器或领域服务。
- `AuditLog` 已追加到 `ptagent-audit.jsonl`，并关联 `X-Request-Id`、登录用户、来源 IP、User-Agent、执行结果和 SHA-256 哈希链；本地启动会检测记录内容或链顺序异常。
- 本地文件仍不能提供数据库事务、独立写入权限、集中留存或真正不可变存储；接入 MySQL/集中日志后，应使用最小权限、备份和必要的 WORM 策略完成生产审计。
